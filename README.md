# tassianoalencar.com.br

Página pessoal (currículo) de Tassiano Alencar, publicada pelo GitHub Pages com o domínio `tassianoalencar.com.br`.

- Conteúdo: `index.html`.
- Estilo: Tailwind compilado. Depois de mudar classes no `index.html`, rode `npm install` (uma vez) e `npm run build`,
  que gera `estilo.css`. Faça o commit do `estilo.css` junto.
- `CNAME` guarda o domínio. Não apague.
- Este repositório é separado de `tassianoalencar.github.io` de propósito: assim as páginas `maguh-assistente` e
  `obd2-dashboard-site` continuam nos endereços `tassianoalencar.github.io/...`.
